# A5 delivery topology decision

`PROTECTED_SAME_ORIGIN_PROXY_RETAINED`. It is the only repository-evidenced design that applies the existing release and Reading Pass checks before metadata and byte zero without exposing a provider URL. Direct signed URLs and CDN-signed delivery may reduce proxy traffic, but each requires a future owner infrastructure decision and a complete revocation/security design. A public/protected hybrid is incompatible with the current zero-public-audio policy.
