current runtime facts, the reviewed source tuple, and authentic existing-host
receipt verification before the unchanged original claim path can be entered.
The supplied runtime preparation remains disabled and unbound.

and one-shot factory admission. It uses the original pinned profile and database

connecting socket per pool, one-second timeouts, disabled retries and the original
controller event loop are explicit. Constructor uncertainty retains custody.

planned command and all original scope/accounting checks.

refs and three metadata reads before/after the one database snapshot. Arbitrary
queries, fallback, pagination and retries are not provided. Unresolved tasks and
uncertain clients retain claim/lock custody. A file hash, generic boolean or
receipt-shaped JSON is not an authenticated issuer.

receipt verifier and dispatcher. It has no default issuer, signer, credential
loader or provider implementation. Genuine verifier/dispatch/runtime provenance
must be supplied and reviewed; this source does not manufacture it.
