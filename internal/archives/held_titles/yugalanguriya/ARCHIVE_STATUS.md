# Yugalanguriya archive status

Yugalanguriya is on publication HOLD and is not part of the active pilot or
publication roadmap. Its source book and historical controlled-publication
package are retained here for provenance and rights-history purposes only.

The archived package contains old publication/audio approval flags and
external audio URLs. Those historical fields do not grant current authority:
the active controlled launch allowlist excludes this title, the rights
decision registry records HOLD, and public audio is disabled. Do not copy this
package back into a runtime publication directory or use it to infer clearance.

The source text and recorded chapter readings were moved byte-for-byte. No
chapter-001 ambiguity was resolved, no canonical Bengali text was changed, and
the chapter-004 documented edition variant remains as recorded.

The separate second approval file in the source package is byte-identical to
`approval_evidence.json`; it is retained in this archive as historical input,
not as an additional approval.
