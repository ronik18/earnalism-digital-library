# Failure prevention learned from Open Window and The Selfish Giant

This is a targeted check list, not a request to recreate past machinery.

| Observed failure | Required correction / test before impact |
|---|---|
| Retrying uncertain uploads risks duplicate versions | Durable intent before upload, destination version inventory, exact identity/full bytes/retention reconciliation. Preserve the uncertain attempt; never infer absence from a missing receipt. |
| Missing retention-inspection adapter profiles | Exercise real adapter construction and role-specific profiles with dummy credentials before live wiring. |
| Provider timestamp granularity differs from local intent | Normalize supported whole-second timestamps before durable intent; verify exact request/readback and provider upload-time minimum separately. Retain historical uncertainty if request was not persisted. |
| One-hour keys expire during preparation | Finish offline source, profiles, budgets and tests first; then owner-private grant setup and fresh read-only scope/expiry/lifecycle gates. No extra key after uncertain creation. |
| Bespoke cap installer/outage became the project | Ordinary approved session acceptance uses supported Reading Pass; do not add cap/fence/supervisor prerequisites. Preserve stopped repair/install history without replay. |
| Metadata URL already has query parameters | Use existing URLSearchParams helper; mounted-route request test ensures release truth and transport selector remain distinct. |
| Paused renewal cleared media cookies | Paused authorization retains appropriate cookie state while paused media remains denied. Test actual resume, not just static cookie shape. |
| Paused seek or next segment requests media before renewal | Defer native time/src changes until active renewal resolves. Model all ordered segment transitions and transient source-swap pauses; clear lifecycle handlers on ending/unmount. |
| Loading/source transitions were billable | Only genuine active playback is billable; pause/wait/buffer immediately becomes nonbillable. Compare all server intervals, not merely wallet sum. |
| Many short renewals lose fractional time | Transactional account-level integer microsecond carry, including successive sessions/transfer/end. Never independently round each interval upward. Real transaction race/idempotency tests required. |
| Customer history stops at 100 rows | Owner-scoped stable keyset pagination, exact seconds, safe title/type and late cross-account response guard. Verify older pages in deployed UI without starting a paid session. |
| Cover files pass but runtime cannot publish | Reuse genuine immutable upload receipts; supported canonical promotion in Integration Lane, refresh mirrored manifests/checksums/rights/bootstrap and derived SEO. Do not require writable Git in a serving container. |
| Public package approved but public API drops its fields | Test actual FastAPI response-model serialization through HTTP. Preserve safe delivery mode, package version and measured duration; keep origins/internal proofs/rights/receipts out. Feed that exact response into CTA/adapter/Listener tests. Pure projection tests are insufficient. |
| Direct Listener works but Book page hides listening | Exercise catalogue HTTP + Reader-manifest enrichment + final presentation together. Supported provider-private package identity must match canonical and manifest slug/version/mode/release/QA without a public provider name. Verify Library, Book CTA and direct Listener independently. |
| Frontend change leaves review source fingerprints stale | Compute the actual production surface after the final edit, update all established authorities, and run the workflow-contract test before push. Never substitute a manually chosen hash or count old-head review as current. |
| Generic canary rollout forbids new-title publication | Use supported dedicated proof/receipt/audio-rights-bound package publication. Preserve generic guard and hidden rollback; no fabricated whole-MP3 URL or global legacy audio flip. |
| Reader rights digest relabelled as audio authority | Separate exact descriptor/language/territory/use binding and accepted/nonrevoked audio decision from prospective Reader metadata decision. |
| CI advances through one stale all-audio-hidden assumption at a time | Search impacted consumers before first push: generators/verifiers, Pydantic models, runtime HTTP tests, catalogue/visual fixtures, precise hash pins, cache versions. Assert exact approved title plus denial of unrelated titles, not blanket removal of checks. |
| Runtime package versions look compatible but imports fail | Resolve the full pinned dependency/import closure (including sox), not a hand-picked no-deps subset. Run no-inference import validation before large model downloads, inside the approved setup budget. Metadata-only inspection is not runtime readiness. Do not replay a consumed allocation to repair it. |
| Repeated owner approvals after deterministic setup mistakes | Finish free diagnosis and real worker-contract checks autonomously. Reuse actual authority; propose any justified setup-repair/allocation envelope once. Explicit single-allocation/no-retry limits remain binding and consumed attempts stay consumed. |
| A two-minute freshness assertion rejects normal Colab startup | Preserve the allocation-request clock and approved absolute setup/work/shutdown deadlines; arm release before admission. Do not invent a shorter startup gate or reset the clock when the kernel becomes ready. |
| Dependency/import tests pass but worker rejects the planned model directory | Run the actual worker's no-inference job validator on the final translated job and configuration fixture before compute. Preserve its exact cache/repository/snapshot/revision contract; do not weaken validation or download weights merely to test a path. |
| Browser dependencies exhaust CI deadline | Inspect retained step/download progress. Diagnose actual mirror/routing bottleneck, retain signed packages and all required browsers, test narrow workflow change. Do not blindly extend timeouts or rerun the same failed provider. Supported bounded read-only transport recovery can proceed inside the actual authority; preserve attempt/byte limits. Official archive selection was one supported correction, not a universal mirror setting. |
| Required CI fails before tests on source fetch or setup | Separate infrastructure failure from test results. Preserve source/hash assertions, fix the demonstrated boundary or use a supported bounded read-only retry, then require the actual exact-head job. Local Mongo skips are unperformed; the existing hosted transactional fixture must really pass. Close required published review through its supported exact-head entry point, not an empty commit. |
| Worker rejects wording after audio completes and loses its transcript | Persist authentic raw transcript, done/usage and audio before semantic checks; preserve the original blocked attempt. Diagnose retained bytes without paid replay; any adoption needs actual wording/performance proof. |
| Native ASR output needs later clock/tokenizer reconstruction | Arrange the minimal input-PCM, tokenizer/class-map, native/selected output, normalization and timing exports in the existing journal before inference; see voice engineering. Missing confidence stays unavailable; model cells are not approved paragraph cues. |
| Global networkidle times out on a rendered page | Wait for bounded document load, visible hydrated shell/requested route and required fonts/images. Keep HTTP/error/overflow/focus checks. Pass helper changes into baseline captures too; validate actual browser workflow after modeled tests. |
| Preview login HTML misread as health PASS | Supported provider-authenticated candidate access; require expected JSON/status and actual guest manifest denial. No bypass token in command logs/evidence. |
| Colab setup passes offline but uploaded notebook has stale/unbound cells | Verify actual uploaded source equality, original clock and preservation-receipt bindings before Connect. Admit the actual interpreter/platform and every pinned wheel before installation/model downloads. No compute merely to discover predictable dependency gaps. |
| Long model cell prevents reliable notebook save/readback | One persistent model worker, short completed foreground cells; per-take archive, full-byte external readback and honest typed ACK before the next unit. Stop on failed retention; never fake a saved-notebook flag. |
| Save/reload or sign-out interrupts a run | Preserve finished output and exact completed-cell archive first; verify hashes and actual ACK state, retain original runtime clock. Restore existing sign-in only through normal owner flow. Never replay an uncertain take or allocate a replacement without authority. |
| Previously accepted units are regenerated after a partial run | Maintain exact selected-ID/word-coverage manifest across runs, immutable original hashes and attempt ledger. Produce only unattempted/authorized corrections, retain each master and assemble losslessly with complete joins/timing/wording QA. |
| Final HTTP fixture passes but real book detail stays audio-disabled | Do not replace the finder in the only HTTP test. Exercise the real candidate lookup/merge with stale approved legacy conveyor; canonical protected package wins only within its validated contract, explicit denials fail closed and legacy formats retain behavior. |
| Backend ready but title absent from Audiobooks filter | Reconcile compiled frontend protected-title allowlist, backend release controls and generated static SEO together. Test composed discovery and direct Book/Listener separately; keep the global audio flag false. |
| Rights regress when publication metadata changes | Recompute exact Reader/cover component bindings, registry/bootstrap and both mirrors after final metadata edits; preserve existing territory/uses/validity and separate accepted audio authority. |
| Provider Git SHA absent on a manual backend artifact | Use reviewed actual runtime file measurement and independent exact-Git inventory comparison, with scope limits; never fill null SHA from a local label. See runbook serving-source procedure. |
| Repository auto-deploy false mistaken for provider auto-deploy off | Verify live Git config and provider createDeployments separately. Change provider settings only when authorized; read back both values and unchanged aliases without a test deployment. |
| Prior success mistaken for current release | Exact head on every required CI/review, reviewed/merged tree equality, exact source startup/health/DB, real candidate ID and both production alias IDs. No redeployment of a completed job. |

## Recent cross-title boundaries

| Symptom | Smallest supported next action |
|---|---|
| Music stops after the opening despite a mixed stem | Audit cue coverage and actual encoded-mix audibility through every unit; explicit deliberate silence stays distinct from missing score. Reuse healthy narration. |
| A named voice turns out to be another provider or narrator | Bind provider/voice ID/model/request/rights to actual audio. Filenames are locators; never relabel or borrow a licence. |
| A high sample or mean hides a material defect | Keep genuine per-book named scores, overall and confidence separate; full frozen scored review and all fatal/per-dimension/objective gates still apply. |
| New backend fails on stale startup canaries | Before another build, use bounded authorized full-guard comparison; preserve exact current/proposed bytes and compatible recovery. Never disable the guard. |
| Exact source and health are treated as guard execution proof | Verify effective normal start/lifespan path as well; `--lifespan off` defeats that inference. Keep unperformed boot/principal/marker evidence explicit. |
| Public Reader200 is mistaken for an exposed audiobook | Verify the distinct protected AUDIO endpoint and application AUTH_REQUIRED denial, plus actual Book/Listener presentation. |
| A tiny timestamp overrun tempts a generic tolerance | Use the canonical source-proven BSON precision/lease interval method; preserve raw history and stricter whole-credit/metered-time counters. |

See [campaign execution](campaign-execution.md) for these decision boundaries, durable intent and failure recovery without a new per-title framework.

Apply only checks relevant to changed inputs plus required repository gates. Retained evidence may be reused only when its edition/package/runtime dependencies remain applicable. Objective tests are not an actual human listening score or a new paid production playback observation.
