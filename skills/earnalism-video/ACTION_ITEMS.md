# GO LIVE action register

Follow [the lean release policy](references/GO_LIVE.md). This replaces older research-heavy release backlogs.

| Stage | Required result |
|---|---|
| Inspect/protect | Correct candidate, unchanged source notebook and isolated outputs. |
| Research/explain | Supported claims, accurate topic model, clear scene progression, one truthful title/cover per format. |
| Produce | Authorized original B narration, actual-audio captions/timing, independent landscape/Shorts, approved branding. |
| Qualify | Factual, graphical/caption, rights, real listening/AV and technical/delivery checks; no unresolved concrete defect. |
| Decide once | One human decision bound to the final candidate; internal criterion records need no separate permission prompts. |
| Deliver | Existing authorized storage/watch route or manual YouTube checks and verified readback; actual live evidence before claiming publication. |

Optional improvement: first-time/card-choice studies, competing packaging variants, analytics checkpoints, detailed cost logs and cadence experiments. Use them when useful or requested; missing results are unknown and do not block primary qualification. Known concrete failures remain holds until resolved. Keep current Moon editions private and preserve B/audio until their own primary qualification and final decision are complete.
