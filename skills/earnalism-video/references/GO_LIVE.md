# Lean release policy

This policy implements the latest owner instruction to make GO LIVE efficient. It supersedes older references, action registers and coverage tables wherever they add redundant approval layers or make optional growth research a release blocker. Preserve useful creative guidance and primary safeguards. No current media, approval or spending allowance changes here.

## One final decision, supported by primary evidence

| Primary criterion | Evidence required before release |
|---|---|
| Facts | Authoritative support for spoken and visual assertions; accurate scope/qualifications; no unresolved factual finding. |
| Graphics and captions | Tested topic model; actual frames/transitions and complete playback of both compositions; readable labels, caption accuracy/synchronization, clearance and a truthful title/cover promise. |
| Rights | Source/model/asset/music licensing and provenance, applicable owner attestations and actual platform restrictions. Reuse valid unchanged clearance; do not request the same attestation again. |
| Listening and audiovisual quality | Real full listening, clear speech and joins, appropriate score/silences, no unresolved perceptual defect and correct A/V synchronization. Verified identical audio may share listening evidence; both visual formats still require complete viewing. |
| Technical and delivery | Current manifest/file hashes, appropriate streams/dimensions/durations, sound, safe peaks, decode evidence, reliable player/captions/Replay and actual retrieved delivery checks. Verify the real destination when claiming it is live. |

Gather these conclusions into **one consolidated decision bound to the exact final candidate manifest**. The same competent reviewer may cover multiple criteria. Internal claim/frame/technical records are evidence, not separate owner permissions or a demand for multiple reviewers. Never prefill human fields from tests or self-scores. Reuse valid unchanged approval; changed media needs affected evidence and a decision covering the revision. A selected voice direction needs no repeated style audition/approval; new speech still needs real final listening.

## Optional improvement work

First-time participants, card-choice studies, title/cover alternatives, detailed audience plans, analytics, cost journals and cadence experiments are **advisory**. Missing or pending research cannot block primary qualification. Use a concise creator-filled audience/learning brief, meaningful scene sequence and adequate packaging; require no owner forms or competing variants.

Known factual errors, overlaps, unreadable captions, misleading covers, audible defects and broken delivery remain primary holds. Fix them and repeat affected checks; no external study is needed merely to reconfirm a correction. Retain honest results when research is used; invent no people, metrics or outcomes.

## Execute efficiently

Resolve the active edition once. Preserve B/soundtrack for visual work and reuse evidence for unchanged assets/conditions. Player changes need playback checks; audio changes need timing/listening; animation changes need affected graphical review. Preserve history and fixture prohibitions.

Do not add arbitrary seven-day policy/route expiry gates or require unrelated monetization/analytics research for a routine release. Check actual availability and applicable current rules once at delivery; reuse valid unchanged clearance and attestations.

Use quick preflight and focused regressions. Run `scripts/verify.py --project PROJECT --full` when software changes or risk justify it. Docs-only changes need links/frontmatter/consistency checks, not new renders, decoding, media approval or full suites. Finish with `python3 video_studio/studio.py check CANDIDATE`.

The existing flat-interface refraction package uses an explicit `earnalism.refraction-publication-profile.v1` JSON file with that same `studio.py check PROFILE.json` command; never invent a Moon `episode.json` to fit its folder layout. This internal adapter binds the immutable media kit, original narration/ASR, factual and graphical evidence, actual delivered captions and platform review. `PRIMARY_CHECKS_READY_PENDING_OWNER_DECISION` prepares the one final review; it grants no publication approval. A later explicit owner decision binds both the kit manifest and stable `candidate_sha256`, covering delivery-caption, saved-setting or actual-video-ID changes without expiring valid approval merely because a recheck timestamp changed. The checker never creates that decision or performs publication, and unresolved findings and fixture prohibitions still apply.

Continue authorized routine work. Ask only for missing access/topic, new paid allowance, user-only authentication or the one final decision. GO LIVE authorizes no purchase, secrets request, new CMS/payments, bulk workflow or automatic YouTube upload. Recheck applicable official policies and actual processing/disclosure/audience/copyright results during manual delivery. A local pass is not proof of upload, deployment or legal certainty.
