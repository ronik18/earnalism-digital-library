# Topic-relevant hashtags by platform

Owner rule — 15 November 2026: include **#earnalism #learnalism #theearnalism together** in every future published YouTube video/Short description and Instagram, Facebook or X video/post caption. Preserve these exact lowercase spellings. This does not authorize publishing, editing old posts, new services or spending.

## Select for fit, not a promised viral multiplier

At each episode’s packaging, identify the actual subject, viewer question, language and intended audience, then make a brief current platform-specific hashtag check. Reuse valid research for unchanged copy in the same release; do not copy a permanent optional tag bank between topics. Shortlist only tags that accurately describe the finished content. Check relevant native suggestions/search results when available; inspect meaning and context, not merely the largest post count. Trending, popular or suggested does not mean a tag will increase this video's distribution. Do not claim a tag is tested, unrestricted or currently trending without dated evidence. A missing search surface is a data limitation, not a release blocker.

Keep the mandatory brand trio, then choose the smallest useful set of specific topic and audience/category tags. Remove duplicates, misleading translations, unrelated seasonal/geographic tags, engagement bait and generic #viral/#fyp/#explorepage fillers. A bilingual library brand does not make every English science episode Bengali content. Do not fabricate hashtag-volume estimates or use a permanent copied tag bank across unrelated subjects.

## Instagram Reels and posts

Use natural topic terms in the caption as well as a few directly relevant hashtags. **Provisional operating default: at most five total: the three mandatory brand tags plus up to two precise topic tags.** This is a conservative operating limit, not a proven optimal count or a claim that every account exposes the same control. Verify the live composer’s actual limit, retaining all three brand tags and reducing optional tags first. If the interface cannot accept the mandatory trio, report that specific restriction; do not silently drop a brand tag or stuff comments to bypass it.

Template: `#earnalism #learnalism #theearnalism #[SpecificMechanism] #[RelevantSubject]`.
Example for evaporation, not a universal default: `#earnalism #learnalism #theearnalism #Evaporation #WaterCycle`.

## YouTube landscape and Shorts

Keep the searchable title readable; place the brand trio and a small relevant topic set in the description. YouTube can suggest hashtags and choose up to three to display near the title; do not promise which will display or confuse these with Studio's internal Tags field. More than 60 hashtags causes YouTube to ignore all hashtags; this is a policy ceiling, never a target. Misleading/unrelated tags can trigger removal. #Shorts is not required to make a qualifying video a Short; add a format tag only when it adds useful accurate context.

Template: `#earnalism #learnalism #theearnalism #[SpecificTopic] [optional relevant series/category]`.
Example: `#earnalism #learnalism #theearnalism #Evaporation #EverydayScience`.

## Facebook and X

For Facebook, keep all three brand tags in the saved caption and add only a few useful topic tags supported by the finished video and current search context. Inspect the actual Page composer; do not assume a universal optimal count.

For X, retain all three owner-required brand tags within the actual account’s character limit. X recommends no more than two as a best practice but allows more; this owner preference deliberately uses three. Add an optional specific topic tag only when it improves context and fits concise useful copy. Do not buy an upgrade or remove a required brand tag to add a trend.

## Fast pre-publication check and learning loop

- Confirm the exact brand trio, unique tags, topic/language fit and current composer acceptance. Verify the saved public caption/description after an authorized publication; a filled form is not proof.
- Record the chosen set, platform, current lookup/source, selection rationale and date with the episode's packaging. If a search surface is unavailable, label optional tags as editorial selections rather than researched trends. No private account figures go into reusable skill files.
- Treat hashtag changes as a low-cost secondary experiment after the hook, explanation and packaging. Keep the brand trio fixed; vary only the optional set when feasible. Use the existing 24-hour, 7-day and 28-day review checkpoints, platform-specific reach/discovery and follower/subscriber conversion where exposed, with comparable format, length and publication age. Retention, saves and shares are guardrails; missing attribution stays unknown. A before/after difference is observational, not a randomized causal test.
- Adopt an optional tag pattern only after repeated relevant observations; revise or retire it when meaning, platform guidance or audience evidence changes. Do not repeatedly edit live metadata to chase noise or add an approval loop.
