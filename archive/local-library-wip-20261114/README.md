Original base: `20aa0a0200ba9ae914572e53fbde7525974f501f`. Files are archived under `files/` to avoid overwriting current production code. These changes require reconciliation before integration. Cloud-only files remain untouched. Known credentials were screened; this archive was not validated as an executable application.
